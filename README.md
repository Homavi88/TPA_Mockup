# TPA Mockup — презентационный макет

## Назначение

`mockup/index.html` — самодостаточный HTML-макет TPA для показа интерфейса.

Макет:
- не подключается к БД и не вызывает API;
- использует реальные партии `QRA0R` за `2026-09` из PSS4 для списка, деталей и сравнения;
- DRY YIELD оставлен демонстрационным, потому что ODC-куб недоступен;
- должен открываться двойным кликом в браузере;
- использует вшитый base64-логотип `static/logo.png`;
- в UI показывает только `BatchIdent`; внутренние `db_id`, `BatchID` и `SAP` не отображаются.

Текущая структура — прежний UI TPA, но визуальное оформление взято из `DESIGN.md`:
- кремовый фон `#fdfcfc`;
- моноширинный шрифт;
- плоские панели без теней;
- hairline-границы;
- интерактивные элементы с радиусом `4px`;
- семантические цвета: accent `#007aff`, danger `#ff3b30`, warning `#ff9f0a`, success `#30d158`.

## Что изображено на макете

Партии, параметры и PPL в макете — реальные данные PSS4 за `2026-09`. DRY YIELD — демонстрационный, так как ODC-куб недоступен.

### Общая сцена

- Макет показывает одностраничный интерфейс TPA для смеси `QRA0R` за период `2026-09`.
- В панели партий показано 7 реальных партий из 30 доступных за месяц.
- Выбраны 2 партии:
  - `1100903` — `QRA0R V.19`, `2026-09-11`, DRY YIELD `86.7%` (демо);
  - `1200902` — `QRA0R V.19`, `2026-09-20`, DRY YIELD `89.6%` (демо).
- Основной сценарий: оператор переходит в `AI Анализ` и запускает имитацию реального чата с агентом — разбор потока табака на входе FTD по 14 партиям (`TPA_AI_Chat_.md`).
- Ключевая история AI-чата: поблендовый разброс WB-Speed / расчётного потока, факторы на входе FTD и параметры, которые задают скорость потока; панель справа по-прежнему показывает сравнение `1100903` vs `1200902`.

## Модальное окно «О блоке»

Окно показывает, какой блок открыт сейчас и что он означает.

Открывается:
- автоматически при загрузке макета через 450 мс, стартовый блок — `01 · BPWATTS — кратко`;
- автоматически при смене вкладки, если окно было закрыто, через 420 мс;
- по кнопке `[?] О блоке`;
- по клику на `#blockIndicator`.

Закрывается:
- крестиком `#btnBlockModalClose`;
- кликом по фону;
- клавишей `Esc`.

Навигация внутри окна:
- `[←] Пред. блок`;
- `След. блок [→]`;
- стрелки клавиатуры `←` / `→`.

При навигации:
- для вкладок меняется активная вкладка в фоне;
- для псевдо-блоков `about`/`tool`/`next` (сторис-страницы 01–03) активная вкладка не меняется; spotlight снимает размытие со всей `.topbar`, бейдж скрывается, а в случае `about` подсвечивается topbar-кнопка `📖 BPWATTS`;
- для сторис-страниц `about`/`tool`/`next` дополнительно отключены blur-панели: страница под модальным окном остаётся без размытия и без полупрозрачной подложки;
- меняется `#blockIndicator`;
- меняется заголовок и текст окна;
- обновляется счётчик вида `1 / 7`; для блоков вне списка (вручную открытые вкладки) — `— / 7`.

Фон:
- пока окно открыто: blur-слои `blur(4px)` и полупрозрачный фон `rgba(253, 252, 252, 0.34)` накрывают макет вокруг активного блока;
- без размытия остаётся активная область блока (`.detail-panel`) или вся `.topbar` для псевдо-блоков;
- стрелка не используется;
- активный блок выделяется компактным синим бейджем `#blockBadge` с подписью блока;
- активная вкладка дополнительно подсвечивается акцентным цветом;
- модальное окно всегда остаётся по центру (`justify-content: center`) и не сдвигается по горизонтали;
- spotlight и бейдж пересчитываются при открытии, навигации, анимации вкладки, скролле и resize;
- при закрытии: все blur-слои, рамка и бейдж исчезают.

Подсветка активного блока:
- при открытии модального окна на `body` добавляется класс `block-modal-open`;
- `.modal-backdrop` больше не размывает фон: он прозрачный и нужен только для окна и клика мимо;
- `resetModalAlignment()` сбрасывает `transform` у `.modal`, чтобы окно не смещалось;
- `.spotlight-overlay` содержит четыре `.spotlight-pane` (top/bottom/left/right), которые формируют blur-фон вокруг `.detail-panel` или всей `.topbar` для псевдо-блоков;
- `#blockBadge` — фиксированный компактный бейдж, он ставится рядом с видимой частью `.detail-panel`; для `about` / `settings` бейдж не показывается;
- позиция бейджа и spotlight-панелей пересчитывается при открытии окна, переходе между блоками, завершении анимации вкладки, скролле и resize;
- при закрытии окна класс, бейдж и blur-панели убираются.

## Как менять конкретные части

### Сменить текст описания блока

Изменить объект `blockInfo` в `<script>`.

Пример:

```js
"tab-single": {
  title: "[+] 04 · Партии",
  text: "Текст, который будет в модальном окне.",
  points: [
    "Пункт 1",
    "Пункт 2"
  ]
}
```

### Сменить подпись блока в полосе индикатора

Изменить `blockLabels`.

Пример:

```js
"tab-ai": "[+] 02 · AI"
```

### Сменить порядок переключения блоков

Изменить `blockOrder`.

Пример:

```js
const blockOrder = ["about", "tool", "next", "tab-single", "tab-ai", "tab-compare", "tab-blendai"];
```

### Сменить силу размытия фона

Изменить `.spotlight-pane`:

```css
.spotlight-pane {
  background: rgba(253, 252, 252, 0.34);
  backdrop-filter: blur(4px);
  -webkit-backdrop-filter: blur(4px);
}
```

Для более слабого эффекта уменьшить `blur()` и/или alpha-канал фона.

Для полного отключения размытия на конкретном псевдо-блоке:

```css
body.block-about-open .spotlight-pane {
  background: transparent;
  backdrop-filter: none;
  -webkit-backdrop-filter: none;
}
```

### Сменить демо-данные

Менять HTML:
- таблицу партий;
- `.detail-header`;
- таблицы вкладок;
- текст AI-ответа;
- панель параметров AI.

Не использовать реальные чувствительные данные в макете.

## Замечания

- В `index.html` могут остаться неиспользуемые CSS-правила старого внешнего слайд-каркаса. Они не влияют на отображение, но при чистке их можно удалить.
- DRY YIELD в макете — демо-значения: ODC-куб недоступен, поэтому реальные yield-значения не вытаскиваются.
- В UI показывается только `BatchIdent`; `db_id`, `BatchID` и `SAP` скрыты.
- В макете не должны появляться персональные, финансовые, клиентские или сервисные секреты.
